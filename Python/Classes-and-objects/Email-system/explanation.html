tory = User('Tory') → ramy = User('Ramy')
Step 2: User objects are passed when sending email
tory.send_email(ramy, 'Hello', 'Hi Ramy!')
Step 3: Email stores the User objects
self.sender = sender (tory User object)
self.receiver = receiver (ramy User object)
Step 4: display_full_email() accesses the names
self.sender.name → tory.name → "Tory"
self.receiver.name → ramy.name → "Ramy"

        return f"[{status}] From: {self.sender.name} | Subject: {self.subject}"

Email Class Explained

📝 Email Representation

The Email class represents individual email messages with sender, receiver, subject, body, timestamp, and read status.

⏰ Automatic Timestamp

Each email automatically records when it was created using datetime.datetime.now(), providing a precise creation timestamp.

🔤 String Representation

The __str__ method provides a clean, formatted string showing the email's status, sender, and subject for easy display.

👥 Object References

self.sender and self.receiver store User objects, not just names. This allows accessing self.sender.name to get the actual name.

Inbox & User Classes

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()

    def send_email(self, receiver, subject, body):
        email = Email(sender=self, receiver=receiver, subject=subject, body=body)
        receiver.inbox.receive_email(email)

Inbox & User Explained

📬 Inbox Management

The Inbox class manages a collection of emails and provides methods for receiving, listing, reading, and deleting emails.

👤 User Objects

Each User has a name and their own Inbox instance. Users can send emails to other users and manage their own inbox.

🔄 Object Collaboration

When a user sends an email, it creates an Email object and delivers it to the receiver's inbox, demonstrating object interaction.

🎯 Name Storage

The User's name is stored when created: User('Tory') → self.name = 'Tory'. This name is later accessed through object references.
